# Maestro - Personal Tutorial Tracker

> An Android application designed to manage personal piano learning progress, integrated with the YouTube API and Firebase.

### 📖 The Story Behind The App

As the final project in my high school Android development track, I wanted to build an app I could actually use in my day-to-day life for one of my hobbies: playing the piano.
When transitioning from music sheets to YouTube tutorials, I constantly struggled to track my progress, manage my active songs, and remember my exact stopping point in each video.
Maestro was designed to solve this need, resulting in a functional, cloud-connected product.

### ✨ Key Features


* **Session Tracking:** Manages learning progress and remembers the exact stopping point for each song.
* **In-App Tutorials:** Integrates the YouTube API to play video tutorials directly within the application.
* **Cloud Sync:** Uses Google Firebase to securely store and sync user data across sessions.

### 🛠️ Built With

* **Language:** Java
* **Platform:** Android SDK
* **Backend:** Google Firebase
* **External APIs:** YouTube Data API
